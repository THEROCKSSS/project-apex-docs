01 / FOR PLAYERS

From an invitation to a server.

The intended player journey is simple. A Windows setup EXE, React launcher, desktop shortcut, repair, uninstall and support export have been exercised in the lab. Automatic game provisioning and independent network invitations are still being developed; the steps below describe the complete target experience.

  1. Install Project ApexRun the setup EXE and use the desktop shortcut. Setup checks explain missing prerequisites.
  2. Choose a communityImport the owner’s network invitation. Review who operates it before signing in.
  3. Prepare the gameA compatible build adapter uses an isolated copy of your own installation and records reversible changes.
  4. Browse and playChoose a real server in the native browser. Join authorization belongs to that host; discovery is optional.
Current lab evidence

One full-size Wakistan server, a native browser-to-world join, two basic opposing bots, 26 native earned-XP events totaling 18,000 XP, and a visible native leaderboard entry have been verified. The native menu restored that saved XP as rank 2. Pilot-seat entry and full engine power were observed; an earlier bounded assisted takeoff is recorded separately. Unassisted flight and landing, full master-service egress isolation, and hydration of the server’s in-round native profile remain open checks.

If setup fails

The launcher’s first slice records bounded setup and failure codes and offers a sanitized support report. Preview the report before sharing it. Raw game logs can contain private data and are not part of the public research site.

Removing it

The installer is designed to remove the application and its shortcuts through Windows Settings. The game installation remains separate. Saved application data is preserved unless you deliberately remove it.

02 / FOR HOSTS

Your network. Your rules.

Host a community

Each independent operator should own their accounts, listings, moderation and clan approvals. Players choose which operator they trust. Separate XP on every server is a fixed requirement.

PARTIAL / LOCAL SERVICES

Share a direct invitation

A network invitation identifies the host and compatible service. It must not include an administrator credential. Direct admission should keep working when an optional directory is unavailable.

PLANNED / NETWORK INVITATIONS

Open to the Internet

Public hosting needs verified game/query listeners, host authentication, explicit ingress, resource limits and reconnect tests. Publishing a listing does not automatically make a host reachable.

PLANNED / PUBLIC HOSTING

What already exists

The independent community API implements scoped credentials, per-server earned XP and leaderboards, pending clan applications, administrator approve/reject/suspend decisions and a configurable name blacklist. The private HTTP API now also has a direct server-authorized profile lookup, with server isolation, fresh XP reads, revocation and approved-clan filtering exercised through the real application boundary in tests. That route is not deployed or wired into native admission yet. Username/password login, remote Steam-ticket verification and network federation are not implemented yet.

03 / RESEARCH NOTES

Evidence before conclusions.

The installed Unity/IL2CPP build contains native machine code. A decompiler can help explain it, but that output is not the original source and does not automatically compile into a matching game.

  1. Pin the input. Hash artifacts and state exactly which build and byte regions are measured.
  2. Follow a question. Use REA’s session and function tools, saved metadata and references to trace one behavior and its state changes.
  3. Reconstruct source. Write typed source for a bounded function, recording its dependencies, ABI, compiler, linker and layout.
  4. Compare and exercise. Compile fresh code, compare its bytes with the pinned extent, then run finite behavioral probes. Keep helper code out of the matching total.
  5. Record the gap. Keep unexplained code, data, assets, indirect calls and runtime uncertainty visible. Never replace unknowns with a completion claim.

    (void)method_info;

}

    (void)method_info;
    value->base += value->additional;
    value->additional = 0;

{
    (void)method_info;

/* Complete TeamManager.GetXP caller in the pinned Win64 build.
 * Metadata/class initialization and the direct float-math helper are external.
 * In particular, rank_math is not replaced with sqrt or the managed Pow wrapper.
 * Partial class layout represents only the two fields this caller reads.
 * The result is a uint32 threshold; it is not a leaderboard position.
 */
typedef unsigned char uint8;
typedef unsigned int uint32;
/* Minimal Win64 SSE2 intrinsic types, independent of SDK headers. These typed
 * conversions preserve the observed binary64 intermediate and packed rounding
 * operation; contemporary compilers fold an ordinary C double cast away.
 */
typedef union __declspec(intrin_type) __declspec(align(16)) __m128 {
    float lanes[4];
} __m128;
typedef struct __declspec(intrin_type) __declspec(align(16)) __m128d {
    double lanes[2];
} __m128d;
__m128 _mm_cvtpd_ps(__m128d value);
float _mm_cvtss_f32(__m128 value);
__m128d _mm_set_sd(double value);
#pragma intrinsic(_mm_set_sd, _mm_cvtpd_ps, _mm_cvtss_f32)

static __forceinline float rank_as_float(uint32 value)
{
    return _mm_cvtss_f32(_mm_cvtpd_ps(_mm_set_sd((double)value)));
}

/* Complete 307-byte float-math error caller, registered as handle_errorf.
 * Credit requires its current source/object/linked/loaded proof to pass.
 * Internal helper names/types are SDK attribution and caller transport;
 * this source does not implement errno, matherr, FP exception or GS helpers.

typedef unsigned int uint32;
typedef unsigned __int64 uint64;

/* Layout used at the call boundary: 16-byte header, three 32-byte operands.
 * The union's alignment and the flag positions follow the installed fpieee.h
 * and the retained _FPIEEE_RECORD debug type; unrelated fields remain opaque.
 */
typedef struct {
    __declspec(align(16)) union {
        float single;
        uint64 words[2];
    } value;
    uint32 valid : 1;
    uint32 format : 4;
} FloatExceptionOperand;

typedef struct FloatExceptionRecord {
    uint32 context[4];
    FloatExceptionOperand first;
    FloatExceptionOperand second;
    FloatExceptionOperand result;
} FloatExceptionRecord;

typedef char OperandSizeMustBe32[(sizeof(FloatExceptionOperand)==32)?1:-1];
typedef char RecordSizeMustBe112[(sizeof(FloatExceptionRecord)==112)?1:-1];
typedef char RecordAlignmentMustBe16[(__alignof(FloatExceptionRecord)==16)?1:-1];

uint64 _ctrlfp(uint64 control,uint64 mask);
int _exception_enabled(uint32 flags,uint64 control);
void _raise_excf(FloatExceptionRecord *record,uint64 *control,int flags,
                 int operation,float *first,float *result);
unsigned char __acrt_has_user_matherr(void);
double _call_matherr(int type,int error,char *name,double first,double second,
                    double result,uint64 control);
void _set_errno_from_matherr(int type);

__declspec(noinline) float handle_native_errorf(char *name,int operation,
    uint64 value,int type,int flags,int error,float first,float second,int count)
{
    FloatExceptionRecord record;
    uint64 control;
    union { float single; uint32 bits; } bits;
    float result;
    *(volatile uint64 *)&control=_ctrlfp(0x1f80,0xffc0);
    bits.bits=(uint32)value;
    /* Preserve the observed integer-store / float-load / float-store transport.
     * The volatile lvalue applies only to this automatic local representation;
     * it does not introduce an external state or an exception implementation.
     */
    result=*(volatile float *)&bits.bits;
    if (!_exception_enabled(flags,control)) {
        if (count==2) {
            record.second.value.single=second;
            record.second.format=0;
            record.second.valid=1;
        }
        _raise_excf(&record,&control,flags,operation,&first,&result);
    }
    if (__acrt_has_user_matherr() && type) {
        return (float)_call_matherr(type,error,name,(double)first,
                                   (double)second,(double)result,control);
    }
    _set_errno_from_matherr(type);
    _ctrlfp(control,0xffc0);
    return result;
}
tools/reconstruction/math_exception.c
/* Complete exception-mask caller candidate, original RVA 0x87f2cc.
 * Matching credit requires the registered whole-body and owned runtime proof.
 * The setter's uint64 prototype has SDK CodeView support; its implementation
 * remains external. The caller zero-extends its small status constants.
 * this file does not implement the actual CRT floating-point status effects.
 */
typedef unsigned int uint32;
typedef unsigned __int64 uint64;

void _set_statfp(uint64 flags);

__declspec(noinline) int exception_enabled(uint32 flags,uint64 control)
{
    int pending=flags&0x1f;
    if ((flags&8) && (control&0x80)) {
        _set_statfp(1);
        pending&=~8;
    } else if ((flags&4) && (control&0x200)) {
        _set_statfp(4);
        pending&=~4;
    } else if ((flags&1) && (control&0x400)) {
        _set_statfp(8);
        pending&=~1;
    } else if ((flags&2) && (control&0x800)) {
        if (flags&0x10) _set_statfp(0x10);
        pending&=~2;
    }
    if ((flags&0x10) && (control&0x1000)) {
        _set_statfp(0x20);
        pending&=~0x10;
    }
    return pending==0;
}
